# Roadmap — Nexora to Azure-Native Target (8 weeks)

This is a sequenced rollout. Items grouped per week are sized to be parallelisable
across two backend engineers + one frontend engineer + one infra engineer. Each
item links to the recommended PR in [pr-structure.md](./pr-structure.md).

Status legend: ◻ not started · ◧ in progress · ◼ done

## Week 0 — Decisions and prework

- ◻ Confirm Azure subscription, target region, BAA coverage (Azure + Anthropic)
- ◻ Reserve resource names: `nexora-{env}-{region}-rg`, `nexora-{env}-cosmos`, etc.
- ◻ Inventory existing managed identities, decide on user-assigned MI for shared services
- ◻ Pick a single environment to bootstrap first (recommended: `dev`)

## Week 1 — MVP RAG pipeline (this engagement)

This is the slice generated by the first code drop. See [rag-mvp.md](./rag-mvp.md).

- ◧ Bicep: Cosmos DB + AI Search + Event Hub + Azure OpenAI with private endpoints
- ◧ Alembic migration: `event_outbox` table per tenant schema with immutability trigger
- ◧ Settings: Azure OpenAI / Cosmos / AI Search / Event Hub config in [backend/app/core/config.py](../../backend/app/core/config.py)
- ◧ Backend services: Event Hub publisher, Cosmos writer, AI Search indexer, Azure OpenAI embedder, RAG retriever
- ◧ FastAPI route: `POST /api/v1/ai/ask`
- ◧ Worker: `python -m app.workers.event_processor`
- ◧ Frontend: AI Assistant panel (TypeScript) with citation chips

## Week 2 — Compliance hardening

- ◻ Add PostgreSQL RLS policies to all per-tenant tables (PR: `pg/rls-policies`)
- ◻ Postgres trigger forbidding UPDATE/DELETE on audit + outbox tables
- ◻ Dockerfile: non-root user, multi-stage build
- ◻ CI: Trivy image scan, `trufflehog` pre-commit, `npm audit` gate
- ◻ Key Vault runtime client; replace deploy-time env injection
- ◻ Azure Policy assignment: HIPAA-HITRUST initiative

## Week 3 — Network hardening

- ◻ Private endpoints: Key Vault, Storage, Service Bus, Event Hub, Cosmos, AI Search, Azure OpenAI
- ◻ Front Door Premium + WAF policy in front of Container App + Static Web App
- ◻ CMK / BYOK for Postgres, Storage, Cosmos
- ◻ DNS private zones for each PaaS service

## Week 4 — Missing domain aggregates

- ◻ Top-level `Provider`, `Encounter`, `Claim`, `Document`, `WorkflowInstance` models + migrations
- ◻ Routes: `/api/v1/providers`, `/api/v1/encounters`, `/api/v1/claims`, `/api/v1/documents`, `/api/v1/workflows`
- ◻ Services: claim adjudication helpers, workflow state machine engine
- ◻ Backfill Member360Claim → top-level Claim with FK
- ◻ Outbox triggers on new aggregates

## Week 5 — Frontend feature work

- ◻ MSAL React + multi-tenant Entra ID config
- ◻ TanStack Query baseline for new modules
- ◻ Claim360 module (mirror of Member360 patterns) in TypeScript
- ◻ Workflow UI (kanban + state machine viewer) in TypeScript
- ◻ Inline AI insights on Member360 dashboard (uses RAG service from week 1)

## Week 6 — Observability + audit

- ◻ Wire `azure-monitor-opentelemetry` in [backend/app/main.py](../../backend/app/main.py)
- ◻ OTEL PHI scrubber processor (regex + denylist)
- ◻ Log Analytics workbook: tenant-scoped audit summary
- ◻ Blob WORM cold sink for `tenant_audit_events` (daily export)
- ◻ Sentinel analytics rules: anomalous logins, mass data export, RAG abuse

## Week 7 — Bicep conversion + DR

- ◻ Convert remaining PowerShell deploy scripts to Bicep modules
- ◻ `main.bicep` orchestrator with per-env parameter files
- ◻ Backup + restore drill (RPO ≤ 24h, RTO ≤ 4h)
- ◻ Cross-region pair for disaster recovery (Active-Passive)

## Week 8 — Release readiness

- ◻ Load test (k6) — 100 RPS sustained on Member360 + AI ask endpoints
- ◻ Security review and penetration test report remediation
- ◻ HIPAA evidence bundle: Log Analytics export + Bicep diff + policy compliance
- ◻ Production cutover runbook + blue/green deploy procedure

## Cross-cutting workstreams (continuous)

- **Documentation** — keep `docs/architecture/` accurate as decisions change
- **Test coverage** — target 70%+ on new backend code; tests are mandatory in every PR
- **Cost governance** — enable Cost Management alerts; budget per RG ≤ $X/month (TBD by Finance)
- **BAA tracking** — log every third-party AI call subject to BAA (Azure OpenAI, Anthropic)
